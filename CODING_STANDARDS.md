# Coding Standards

## Checks

- Не уменьшай покрытие проверок, чтобы пройти CI. Если lint/CI-команда сужается,
  запусти старую команду и объясни причину в ревью.
- Сгенерированные файлы (`api/openapi/`, `web/src/client/`) не редактируются
  вручную. `mise run check` проверяет, что после генерации нет расхождений.
- Механические нарушения закрываются проверкой, а не правилом в документации.
